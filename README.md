Aplicativo Mobile - MJ Music (Protótipo Interativo)

​Visão geral do projeto:

Este repositório apresenta o protótipo de alta fidelidade desenvolvido no Figma para um aplicativo de streaming de música mobile chamado MJ Music. O projeto foi estruturado para simular a experiência real de um usuário ao utilizar uma plataforma de áudio, focando em usabilidade, design intuitivo e fluxos de navegação fluidos (mobile-first).

​Principais Funcionalidades Mapeadas no Protótipo:

​Tela de Autenticação: Fluxos simulados de entrada por e-mail, Google e Facebook.
​Tela Inicial (Home): Recomendações de músicas, álbuns e playlists em destaque.
​Biblioteca e Favoritos: Seção dedicada para o utilizador aceder aos seus conteúdos salvos e favoritos.
​Player de Música Interativo: Telas conectadas que simulam a reprodução, pausa, avanço, retrocesso e controle de faixas de áudio.
​Ferramentas Utilizadas:
​Figma (Prototipagem mobile de alta fidelidade e componentes visuais)
​Técnicas de UI/UX e Arquitetura de Informação

​Como visualizar e testar o projeto:

​Por se tratar de um protótipo de aplicativo mobile focado em interface e fluxo de navegação, a visualização é feita diretamente no Figma.
​Para testar a interatividade (clicar nos botões de login, navegar entre as abas da biblioteca, favoritar músicas e acionar os comandos do player), acesse o link abaixo e clique no botão de "Play" (Present) ou abra através do aplicativo do Figma no telemóvel.

​O que aprendi com este projeto:

​Design Mobile-First: Compreensão prática das restrições e padrões de design para telas de smartphones, priorizando áreas de toque confortáveis e navegação limpa.
​Estados de Tela e Interatividade: Desenvolvimento de protótipos encadeados no Figma para simular comportamentos reais de um sistema (como mudar de faixa ou abrir a biblioteca).
​Arquitetura de Conteúdo: Organização lógica de menus, barras de navegação inferiores e telas de reprodução.

​Como o projeto pode ser melhorado (Próximos Passos):

​Desenvolvimento Mobile Nativo ou Web: Construir a aplicação de fato utilizando tecnologias mobile (como React Native ou Flutter) ou frontend web responsivo.
​Integração com API de Música: Conectar o aplicativo a uma API real de streaming de áudio para reprodução de músicas verídicas.
​Inteligência Artificial e Recomendações: Integrar um sistema de recomendação baseado em IA para sugerir playlists personalizadas com base no histórico de audição do utilizador.
